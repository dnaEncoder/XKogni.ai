07 · Implementation

Theme components through their parent section.

Components should inherit semantic values from a section-level theme attribute. This keeps the codebase consistent and avoids maintaining separate dark and light versions of every component.
<section class="xc-section" data-theme="dark">
  <div class="xc-container">
    <span class="xc-eyebrow">Agentic Overview</span>
    <h2>Our <span class="xc-highlight">Agentic AI</span> Platform</h2>
    <div class="xc-card">...</div>
  </div>
</section>

<section class="xc-section" data-theme="light">
  <div class="xc-container">
    <span class="xc-eyebrow">Platform Overview</span>
    <div class="xc-card">...</div>
  </div>
</section>
Development acceptance rule: every section must use one approved archetype, inherit semantic theme tokens, follow the spacing system, define responsive behavior, and remove unverified metrics, integrations, customer logos, or compliance claims before production.
