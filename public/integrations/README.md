# Integration logos

Drop official brand logo SVGs (or PNGs) here using these exact filenames. Each
one is picked up automatically by the Enterprise Integrations section — no
code change needed. Until a file exists, that card shows its current generic
icon as a fallback.

| Filename | Brand |
|---|---|
| `workday.svg` | Workday |
| `coupa.svg` | Coupa |
| `oracle.svg` | Oracle |
| `sap.svg` | SAP S/4HANA |
| `sharepoint.svg` | SharePoint |
| `dynamics365.svg` | Microsoft Dynamics 365 |
| `aws.svg` | AWS |

Square or near-square marks work best — the card renders each logo at
28x28px inside a circular badge.
